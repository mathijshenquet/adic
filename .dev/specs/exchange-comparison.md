## Deliverable: `aips/draft/exchange-comparison.md` (+ PDF per AGENTS.md recipe)

1. **Define the ℕ-exchange quotient precisely.** The commutative
   monoid M_G of ℕ-edge-costs (or local tables) modulo the
   congruence generated by exchange-with-ℕ-potential and ℕ-word-
   price shifts — write the exact congruence; note it must be a
   monoid congruence (compatible with +). State the canonical
   monoid map M_G → Q_G to the classification report's group.
2. **The kernel question.** Is M_G cancellative? Is M_G → its
   group completion injective? If not, exhibit the smallest
   counterexample — two ℕ-costs identified in Q_G but distinct in
   M_G (or vice versa). This is exactly "what completion forgets",
   stated as elements.
3. **The image/cone question.** Characterize which formal classes
   have nonnegative representatives (relate to §2.5's affine
   semigroup); compute it for the four named examples.
4. **Divisibility.** Where does parity's order-2 statement live:
   in M_G (as a divisibility fact: 2x = trivial-class element with
   x nontrivial) vs in Q_G (honest torsion)? Make the two
   statements and their relation exact — the priorart warned that
   "torsion" language is only safe in the right quotient.
5. **Boyle–Handelman comparison.** Their ordered H¹ = integer
   group + positive cone. Ours differs by (a) the word-price
   quotient, (b) starting in ℕ. State precisely which of our data
   their framework already captures and which not — one honest
   page; cite their definitions concretely.
6. **Lean statements** for the main comparison results, in the
   Cocycle.lean vocabulary (exchange form, no Int in statements
   where avoidable).
