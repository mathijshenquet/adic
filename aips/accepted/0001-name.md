# AIP-1: the language is called adic

Status: accepted 2026-08-09

## 1. The problem

The project needed a name. "nextlang" was a placeholder directory name,
and the proposal prefix derived from it (NIP) was equally placeholder.
A name was wanted before any other artifact landed, so that the
repository, proposal prefix, and paper could be born under it.

## 2. Prior work

Candidates considered, with rationales and collision checks
(web-searched 2026-08-09):

- **adic** — see Recommendation. No PL-space collision found.
- **gradus** — gradation as the core idea; *Gradus ad Parnassum*
  (Fux's counterpoint textbook, "steps toward mastery") suits the
  thesis-length paper ambition. Minor collision: gradus.dev, a small
  tutorials platform.
- **dyad** — the memory geometry itself. Real collisions: "dyadic" is
  entrenched APL vocabulary (two-argument function), and "Dyad" is an
  existing AI app-builder (2025).
- **kraft** — after the Kraft inequality carrying the cursor/fast-state
  accounting (convo [57]). Strong word, but Kraft Foods, and "KIP"
  reads as poultry in Dutch.

## 3. Recommendation

**adic.** The deepest fit: the language's central move is that infinite
types exist only as graded towers of finite ones — and the `uint` tower
is literally the inverse system {ℤ/2ⁿ} whose limit is the 2-adic
integers. "The tower without taking the limit" is the language's whole
stance, compressed into the mathematical suffix that names such towers.
Tree addresses are dyadic intervals, so the memory model rhymes too.
Short, lowercase (it is a suffix, worn as a name), unclaimed.

## 4. Open questions

None outstanding at adoption.

## 5. Decision

Adopted 2026-08-09 by Mathijs, choosing adic from the candidate list
above. Consequences: proposals are **AIPs**; the repository moves from
`~/nextlang` to `~/adic`.
